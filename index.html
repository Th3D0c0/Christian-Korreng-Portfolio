Custom 3D Rendering Engine

Over the summer of 2025 I started to learn C++ andOpenGL. I chose a game engine as the project of choice because it was a good opportunity to get to know the foundation of the tools we use as developers better.

AI was used in this project to help with debugging, C++ syntax and understanding OpenGL functions.

Features include:

-Working lighting using simple Phong algorithm.

-Experimental lighting using Forward+ tiling.

-Planet Generator using Marching Cubes.

-Asset importing using assimp.

-Shader permutation.

-Particle system utilizing spatial partitioning.

-Skybox

-Dear ImGui for GUI

-3D Model imports using assimp

Rasterfari: Custom Rasterizer written in C

In the winter break of 2026 I wanted to learn more about how games render to the screen. So I decided to learn C and how to rasterize to a color buffer.

AI was used to write the MVP matrices and to help with debugging

Features include:

-Triangle Rasterization using Barycentric Coordinates

-Line Rasterization using Bresenham Algorithm
